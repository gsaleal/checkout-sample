# Checkout Sample

This is a simple checkout system demo built with Java and Gradle. It demonstrates the core functionality required for processing checkout operations in an e-commerce system.

## Features
- Simulate checkout processing
- Basic handling of item selection and pricing
- Gradle build automation

## Requirements
- Java 8 or higher
- Gradle 6.0 or higher

## Setup

Clone the repository:

```bash
git clone https://github.com/gsaleal/checkout-sample.git
```
